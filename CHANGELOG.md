# Changelog

## [0.8.0] - 2026-11-12
- Added explicit SQL operator and punctuation coloring inside and outside CDATA.
- Preserved separate colors for strings, comments, XML markup, and MyBatis parameters.

## [0.7.0] - 2026-11-12
- Added consistent highlighting for `#{...}` and `${...}` binding parameters.

## [0.6.0] - 2026-11-12
- Added SQL identifier highlighting and `--` / `/* ... */` comment coloring.

## [0.5.0] - 2026-11-12
- Improved CDATA-aware token scanning and XML/SQL context handling.

## [0.4.0] - 2026-11-12
- Added support for unsaved Untitled mapper buffers.
- Added debounced refresh, per-document caching, and mapper root detection.

## [0.3.0] - 2026-11-12
- Added numeric and string literal highlighting and extension icon.

## [0.2.0] - 2026-11-12
- Added SQL and MyBatis tag colorization.
